## 🧪 测试模式 (--test 参数)

从 v1.9.8 开始，插件支持使用 `--test` 参数快速测试出图效果，无需请求API！

### 使用方法

#### 1. 生成测试数据

首先运行Python脚本生成测试歌单数据：

```bash
cd /path/to/music-link-vincentzyu-fork
python3 generate-test-data.py
```

这会在 `assets/songlist-test.json` 生成包含45首歌曲的测试数据（23首网易云 + 22首QQ音乐）。

#### 2. 使用 --test 参数

在Koishi中使用指令时添加 `-t` 或 `--test` 参数：

```bash
# 落月点歌测试
落月点歌 -t
落月点歌 --test

# 网易点歌测试
网易点歌 -t
网易点歌 --test

# 结合其他参数使用
落月点歌 -t -n 1          # 直接返回第一首歌
落月点歌 -t -s            # 跳过歌单选择
落月点歌 -t -m dark       # 使用暗黑模式渲染
```

### 测试模式特点

✅ **无需网络连接**：直接从本地JSON文件读取数据  
✅ **快速响应**：跳过API请求，立即显示歌单  
✅ **真实数据结构**：测试数据格式与API返回完全一致  
✅ **支持所有渲染模式**：text、svg、puppeteer、markdown等均可测试  
✅ **可自定义数据**：修改 `assets/songlist-test.json` 即可更换测试内容  

### 适用场景

- 🎨 调整SVG/CSS样式后快速预览效果
- 🔧 调试列排列模式（column-first vs row-first）
- 📐 测试不同缩放比例、宽度、列数的视觉效果
- 🌙 对比亮色/暗黑模式的差异
- ⚡ 开发过程中快速迭代，无需等待API响应

### 注意事项

⚠️ 测试模式下不会发送真实的音乐卡片  
⚠️ 歌曲URL为空，无法播放或下载  
⚠️ 歌词显示为占位文本 "[测试模式] 歌词获取已跳过"  
⚠️ 仅用于视觉测试和功能验证，不代表真实使用体验

# 序号输入错误 Bug 修复报告

## Bug 现象

用户输入歌曲序号（如 `1`）后，机器人提示：`❌ 序号输入错误，已退出歌曲选择。`

## Bug 原因

### 旧版本 (v1.8.1)

在 v1.8.1 及之前版本中，`session.prompt()` 是在 `command6.js` 和 `command9.js` 中直接调用的：

```javascript
// command6.js (v1.8.1)
let input = await session.prompt(config.waitTimeout * 1000);
if (!input) {
   return `${quoteId ? h.quote(quoteId) : ''}${session.text(`.waitTimeout`)}`;
}
if (exitCommands.includes(input)) {
   return h.text(session.text(`.exitprompt`));
}

const serialNumber = +input;  // 正确获取用户输入
```

### 引入 Bug 的修改

在后续版本中，为了代码复用，将歌单渲染和用户输入逻辑抽取到了 `index.js` 的 `renderSongList` 共享函数中。

但是修改时漏了一个关键问题：**`renderSongList` 函数获取用户输入后，没有把结果返回给调用方**：

```javascript
// index.js (Bug版本)
let input = await session.prompt(config.waitTimeout * 1000);
if (!input) {
   return `${h.quote(session.messageId)}${session.text(`.waitTimeout`)}`;
   // ❌ 问题：没有返回用户输入内容
}
if (exitCommands.includes(input)) {
   return h.text(session.text(`.exitprompt`));
   // ❌ 问题：没有返回用户输入内容
}
// ❌ 根本问题：没有 return input
```

调用方 `command6.js` 中：

```javascript
const renderResult = await renderSongList(...);
if (renderResult) {
    return renderResult;  // renderResult 不是用户输入
}
// input 仍然是 undefined！
const serialNumber = +input;  // +undefined = NaN
if (Number.isNaN(serialNumber)) {
    return h.text(session.text(`.invalidNumber`));  // 触发错误
}
```

## 修复方案

### 1. 修改 index.js - renderSongList 函数返回值

将用户输入结果包装成对象返回：

```javascript
let input = await session.prompt(config.waitTimeout * 1000);
if (!input) {
   return { timeout: true };
}
if (exitCommands.includes(input)) {
   return { exit: true };
}
return { input };
```

### 2. 修改 command6.js 和 command9.js - 处理返回值

正确解析返回值，提取用户输入：

```javascript
const renderResult = await renderSongList(ctx, session, config, logger, options, songList, formattedList);

// 先判断是否是字符串错误消息
if (typeof renderResult === 'string') {
    return renderResult;
}

if (renderResult) {
    if (renderResult.timeout) {
        return `${h.quote(session.messageId)}${session.text(`.waitTimeout`)}`;
    }
    if (renderResult.exit) {
        return h.text(session.text(`.exitprompt`));
    }
    input = renderResult.input;  // 正确提取用户输入
}
```

## 总结

| 阶段 | 问题 |
|------|------|
| 旧版本 (v1.8.1) | ✅ 正常工作 - session.prompt 在 command6/9 中直接调用 |
| 代码重构后 | ❌ Bug - renderSongList 抽取到 index.js 但未返回用户输入 |
| 修复后 | ✅ 正常工作 - renderSongList 返回 {input} 对象，调用方正确解析 |

**Root Cause**: 重构代码时，将 `session.prompt` 抽取到共享函数后，忘记将用户输入返回给调用方，导致 `input` 变量始终为 `undefined`，`+undefined` 变成 `NaN` 触发序号验证失败。
